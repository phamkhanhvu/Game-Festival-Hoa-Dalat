# Quầy Hàng Đà Lạt

Game 3D trên trình duyệt: điều hành quầy hàng trên Quảng trường Lâm Viên, Đà Lạt.
Chạy bằng cách mở `index.html` qua máy chủ web (không mở trực tiếp bằng file://).

## Cấu trúc
- `index.html`: toàn bộ mã game (Three.js tải từ CDN).
- `lam-vien.json`, `nha-hat.json`, `decor.json`: bản đồ, nhà hát Hoa Dã Quỳ, cây cối và xe cộ.
- `nvboy.json`, `rig01.json` đến `rig10.json`: mô hình nhân vật.
